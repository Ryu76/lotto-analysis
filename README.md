# 최근 50회 로또 번호 분석·조합 생성

동행복권 로또6/45 공식 공개 결과를 조회 시점에 가져와 최근 10·30·50회의 **기술 통계**와 과거 분포 기반의 조합 생성을 제공하는 단일 페이지입니다.

> 당첨번호를 예측하지 않습니다. 모든 로또 조합의 실제 당첨 확률은 동일하며, 추천은 당첨 또는 확률 상승을 보장하지 않습니다.

## 기능

- **저장 없음**: 로컬 DB·엑셀 업로드·추천 결과 영구 저장 없이, 공식 최근 50회 결과를 요청 시점에 메모리에서 분석합니다.
- 공식 최신 결과 조회 후 최근 10·30·50회 분석
- 번호별 출현 횟수·마지막 출현 회차·미출현 기간
- 홀짝 및 번호 구간 구성, 번호 합계, 연속 번호, 직전 회차 중복 통계
- 번호 추천: 균형 / 빈도 / 랜덤 방식, 1·3·5·10게임, 요청 안 중복 조합 방지
- 조합 정보: 합계·홀짝·저고 구간·연속번호 여부
- 버튼으로만 실행하는 워크포워드 백테스트: 균형·빈도·랜덤을 동일 조건에서 비교하며, 대상 회차보다 미래의 데이터는 사용하지 않음

## 추천 방식

- **균형 추천**: 최근 50회의 홀짝·저고·합계·연속번호·직전 회차 중복·밀집 분포를 기준으로 임의 후보를 평가한 후 상위 후보군에서 무작위 선택합니다.
- **빈도 추천**: 전체 출현(30%), 최근 30회(25%), 최근 10회(15%), 미출현 기간(10%), 무작위 요소(20%)를 가중치로 사용합니다. 빈도가 미래 확률을 뜻하지는 않습니다.
- **랜덤 추천**: 통계 조건 없이 Python 표본추출로 1~45에서 중복 없는 여섯 번호를 뽑습니다.
