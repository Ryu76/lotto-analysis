# 최근 50회 로또 번호 분석

동행복권 로또6/45 공식 공개 결과를 조회 시점에 가져와 최근 10·30·50회의 **기술 통계**를 보여주는 단일 페이지입니다. 당첨 번호 추천이나 당첨 가능성 예측은 하지 않습니다.

## 기능

- 로컬 DB·엑셀 업로드 없음: 결과를 저장하지 않습니다.
- 공식 최신 결과 조회 후 최근 10·30·50회 분석
- 번호별 출현 횟수·마지막 출현 회차·미출현 기간
- 홀짝 및 번호 구간 구성
- 번호 합계 범위·평균
- 연속 번호 포함 비율
- 직전 회차와 중복된 번호 수

## 실행

```bash
# 실행 위치: Git Bash 또는 WSL
cd /e/python/lotto-analysis
uv venv .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt
.venv/Scripts/python.exe -m uvicorn app:app --host 127.0.0.1 --port 8040
```

브라우저에서 `http://127.0.0.1:8040`을 엽니다.

## 데이터 출처와 제한

- 출처: 동행복권 로또6/45 공식 공개 결과
- 공식 사이트가 일시적으로 응답하지 않으면 화면에 조회 실패 메시지가 표시됩니다.
- 공식 공개 데이터의 구조 또는 접속 정책이 바뀌면 수집 경로를 조정해야 할 수 있습니다.
- Quick Tunnel URL은 로컬 서버와 tunnel 프로세스가 실행 중인 동안에만 유지됩니다.
